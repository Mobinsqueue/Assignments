Project Description
---

This java program analyzes a year of sales-change data comparing it with the same month of previous year,
Program keeps looping and finds consecutive period of months that have the highest combined sale values and prints their months and total,
if two periods have the same value and tie the first one is kept and next ones are ignored, if every month is negative program takes the highest number among them.

Structure
---
Docs folder include my Design description, pseudocode and test cases and their expected results


Compiling
---
javac src/SalesAnalysis.java

java -cp src SalesAnalysis

Program output
---

The program will find the highest consecutive months and print the starting month, end month, and total sale in that period
